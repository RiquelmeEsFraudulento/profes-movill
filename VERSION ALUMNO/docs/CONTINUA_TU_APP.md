# Tu aplicación, tus decisiones
La base no te obliga a una temática visual ni a mantener todas las pantallas. Puedes crear un álbum, seguimiento táctico, museo deportivo o cambiar a otro deporte con datos verificados. Mantén las evidencias acordadas de RA2/RA3.

1. Describe usuarios, problema y tres historias de uso.
2. Dibuja tres pantallas y el modelo de datos.
3. Decide qué módulos reaprovechas y qué mejoras.
4. Implementa una novedad propia; separa hechos de opiniones personales.
5. Registra una prueba correcta, una de error y una mejora medible.
6. Entrega código comentado, APK, README, vídeo en dispositivo real y matriz de evidencias.

No publiques secretos, claves de firma o datos personales. Justifica procedencia y fecha de los datos, licencias de imágenes, permisos y dependencias. Un enlace no concede permiso para copiar imágenes.
