# Empieza aquí: una tarea cada vez

1. Abre README.md y ejecuta el proyecto.
2. Usa el catálogo: búsqueda, favorito y una nota. Guarda.
3. Entra en Academia. Elige solo una pareja de ejemplo/evaluable.
4. Lee objetivo y no tienes que hacer antes de abrir el código.
5. Ejecuta el ejemplo X. Después abre el archivo E del mismo número.
6. Sustituye el TODO por tu trabajo, sin cambiar la firma.
7. Ejecuta solo sus tests. Revisa primero el primer error.
8. Comprueba la pantalla. Guarda un punto de progreso.

Las casillas son para recordar lo realizado, no para medir rapidez. Puedes trabajar con texto ampliado, por bloques cortos y sin agitar el dispositivo. No hay cuenta atrás en el cuestionario. Si necesitas retomar: escribe «último paso completado» y «siguiente acción» en una nota.

Nombres fijos: X = ejemplo resuelto; E = ejercicio evaluable. El rojo de un test pendiente no significa que hayas perdido el trabajo. Los requisitos obligatorios están en la lista de comprobación, no escondidos en las pistas.

La guía busca reducir ambigüedad y carga de memoria; no presupone que todas las personas con TDAH o autismo necesiten las mismas adaptaciones. El docente puede ajustar formato, sesiones y forma de demostrar el aprendizaje.
