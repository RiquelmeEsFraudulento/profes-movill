# E12 — Datos guardados sin conexión

## 1. Objetivo
Distingue respuesta válida vacía de error. Mantén último resultado al fallar la descarga.

## 2. Antes de empezar
- Ejecuta el catálogo básico. No tienes que resolver los otros 15 ejercicios primero.
- Haz una copia de tu trabajo o un commit.
- Abre Academia en el menú y busca el número 12.

## 3. Ejemplo resuelto que debes consultar
Archivo: app/src/main/java/es/aula/futbol/ejemplos/X12Cache.kt
Ejecuta su botón en Academia. Lee qué entra, qué se devuelve y cuándo se valida.

## 4. Archivo evaluable
app/src/main/java/es/aula/futbol/evaluables/E12Cache.kt
Mantén el objeto y la firma de la función. El TODO es intencional. La interfaz ya llama a esta función: no tienes que reconstruir toda la pantalla.

## 5. Pasos
1. Consulta X12Cache y el tipo CacheResult.
2. Si remote no es null y no hay error, úsalo como dato actual, incluso si está vacío.
3. Si falla la descarga, usa saved y marca stale=true.
4. Distingue mensaje sin datos de mensaje datos guardados.
5. Prueba con respuestas controladas en tests, no con la disponibilidad de una web.
6. La pantalla de red usa un catálogo no vacío; no confundas su regla de producto con el contrato del helper.

## 6. Punto de parada
Puedes parar cuando tu función compile y supere un caso sencillo. Guarda tu progreso antes de continuar con errores y límites. Los tiempos no se usan como criterio de evaluación.

## 7. No tienes que hacer
No cambies los IDs existentes, las firmas de los métodos ni el comportamiento de los otros ejercicios. No necesitas librerías nuevas para el helper. No inventes hechos deportivos. Las ampliaciones personales se acuerdan y se documentan aparte.

## 8. Lista de comprobación
- [ ] Error conserva cache
- [ ] Remoto vacío válido en helper
- [ ] Primera apertura sin datos controlada
- [ ] Fecha de actualización visible al actualizar

## 9. Pruebas automatizadas
Clase: E12Test. Prueba el ejemplo, el contrato y un caso límite.
Comando para este ejercicio: `./gradlew testDebugUnitTest --tests 'es.aula.futbol.E12Test'`
En Windows usa gradlew.bat. Un test rojo por NotImplementedError significa que aún falta tu implementación, no que el proyecto base deba dejar de abrirse.
